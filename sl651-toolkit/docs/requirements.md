> 版本：v1.2.0

## 一、项目概述

### 1.1 定位

提供 **SL651-2014 水文监测数据通信规约** 和 **SL427-2021 水资源监测数据传输规约** 的 Python 编解码工具包，含设备模拟器。

### 1.2 协议范围

| 协议 | 全称 | 依据 |
|------|------|------|
| SL651 | 水文监测数据通信规约 SL651-2014 | 《水文监测数据通信规约（报批稿）SL/T 651-2014》 |
| SL427 | 水资源监测数据传输规约 SL/T 427-2021 | 《水资源监测数据传输规约 SL/T 427-2021》 |

### 1.3 技术栈

- Python 3.10+
- 外部依赖：`PyYAML>=6.0`（仅多站点 YAML 配置需要）
- 模拟器 MQTT 模式：需系统安装 `mqttx` CLI（EMQX 出品，独立二进制）
- 核心解码器/编码器：**零外部依赖**

### 1.4 模块结构

```
sl651-toolkit/
├── sl651/          SL651 协议核心（bcd / crc / constants / decoder / encoder）
├── sl427/          SL427 协议核心（constants / decoder / encoder）
├── simulator/      设备模拟器（base_station / generators / water_level / rain / soil / sender / engine）
├── tools/          CLI 工具（decode_cli / simulate_cli）
├── tests/          测试脚本（test_sl651.py, 17 项）
├── examples/       示例报文与配置
├── docs/           需求与设计文档
└── audit/          审计报告
```

## 二、SL651 协议

### 2.1 帧结构

**HEX/BCD 编码帧（规约表11/表12）**

```
7E 7E | Header(11B) | STX/SYN(1B) | Body(NB) | ETX(1B) | CRC16(2B)
```

**报头（上行，表11）**

| 偏移 | 长度 | 字段 | 编码 |
|------|------|------|------|
| 0 | 2 | 帧起始符 | `7E 7E` |
| 2 | 1 | 中心站地址 | 1B, 范围 1~254 |
| 3 | 5 | 遥测站地址 | 5B, 方式1/方式2 |
| 8 | 2 | 密码 | 2B HEX |
| 10 | 1 | 功能码 | 1B |
| 11 | 2 | 报文标识 | bit7=方向, bit6~0+lo=正文长度 |
| 13 | 1 | 报文起始符 | `02`(STX) 或 `16`(SYN,多包) |

**下行帧（表12）**：`[遥测站址5B]` 与 `[中心站址1B]` 顺序互换。

**正文结构（上行定时/加报/小时报）**

| 偏移 | 长度 | 字段 | 编码 |
|------|------|------|------|
| 0 | 2 | 流水号 | 2B |
| 2 | 6 | 发报时间 | BCD YYMMDDHHmmSS |
| 8 | 2 | F1F1 | 站码标识符 |
| 10 | 5 | 站码 | 同报头遥测站址 |
| 15 | 1 | 测站类别 | 附录A分类码 |
| 16 | 2 | F0F0 | 观测时间标识符 |
| 18 | 5 | 观测时间 | BCD YYMMDDHHmm |
| 23+ | — | 要素数据 | 引导符(1B)+定义符(1B)+数据(NB) |

### 2.3 要素编码

**定义符机制（规约表26）**

每个要素前有 2 字节标识符：**引导符(1B)** + **定义符(1B)**。

定义符编码：
- 高 5 位 = 数据字节数（0~31）
- 低 3 位 = 小数位数（0~7）

```python
# constants.py
def parse_def_byte(b: int) -> tuple[int, int]:
    return (b >> 3) & 0x1F, b & 0x07
```

**要素标识符表（规约附录C）**

| 类别 | 引导符 | 要素 | 特殊类型 |
|------|--------|------|----------|
| 特殊 | `F0` | 观测时间 | 固定 5B BCD |
| 特殊 | `F1` | 站码 | 固定 5B |
| 特殊 | `F4` | 12 组 5min 雨量(均匀报) | F4_ARRAY, 12×1B HEX |
| 特殊 | `F5~FC` | 12 组 5min 水位(均匀报) | F5_ARRAY, 12×2B HEX |
| 雨量 | `1F` | 日降水量 N(5,1) | 普通 BCD |
| 雨量 | `1A` | 1小时降雨量 | 普通 BCD |
| 雨量 | `20` | 当前降水量 N(5,1) | 普通 BCD |
| 雨量 | `26` | 累计雨量 N(6,1) | 普通 BCD |
| 水位 | `39` | 瞬时河道水位 N(7,3) | 普通 BCD |
| 水位 | `3A` | 坝下水位 | 普通 BCD |
| 水位 | `3B` | 坝上水位 | 普通 BCD |
| 流量 | `27` | 瞬时流量 N(9,3) | 普通 BCD |
| 流量 | `28~2F` | 取排水口流量 1~8 | 普通 BCD |
| 流速 | `36` | 断面平均流速 | 普通 BCD |
| 流速 | `37` | 瞬时流速 | 普通 BCD |
| 墒情 | `10~17` | 10~100cm 土壤含水量 | 普通 BCD |
| 气象 | `02` | 瞬时气温 | 普通 BCD |
| 气象 | `03` | 瞬时水温 | 普通 BCD |
| 电压 | `38` | 电池电压 | 普通 BCD |
| 状态 | `45` | 状态报警 | STATUS, 12-bit 掩码 |
| 信号 | `80` | 4G 信号强度 | 80, 长度由定义符编码 |
| 水质 | `46~57` | pH/溶解氧/电导率/浊度/COD/氨氮/总磷/总氮/重金属等 | 普通 BCD |
| 扩展 | `FF XX` | 子标识符（水位传感器、温度传感器等） | 二级扩展 |

**负数 BCD 编码（规约 6.6.3.3a）**

首字节 `0xFF` 表示负数，编码器用 `0xFF` 前缀，解码器剥离后负号运算。

**状态位解码（规约表58）**

`45H` 要素为 12-bit 压缩位掩码：
- BIT0: 交流电充电（0=正常/1=停电）
- BIT1: 蓄电池电压（0=正常/1=电压低）
- BIT2~4: 水位/流量/水质超限
- BIT5~6: 流量/水位仪表故障
- BIT7: 终端箱门（0=开启/1=关闭）
- BIT8: 存储器（0=正常/1=异常）
- BIT9~11: IC卡/水泵/剩余水量

|--------|------|

### 2.5 校验算法

- **算法**: CRC-16/MODBUS (多项式反转 `0xA001`, 初值 `0xFFFF`)
- **覆盖范围**: 从起始符 `7E7E` 到 ETX（含），不含 CRC 自身
- **字节序**: 大端（高位字节在前）
- **验证向量**: `crc16(b"123456789") == 0x4B37`

### 2.6 解码器设计

**输入**: 十六进制字符串或 bytes

**处理流程**:
1. 验证 `7E7E` 起始
2. 解析报头（中心站址、遥测站址、密码、功能码、正文长度）
3. 校验 STX/SYN 报文起始符
4. 提取流水号、发报时间
5. 上行：解析 F1F1/站码/测站类别/F0F0/观测时间（如不存在则走简约路径，适配2F/35）
6. 下行：直接进入响应数据区
7. 逐要素解析：引导符 → 定义符（动态获取字节数+小数位）→ 数据值
8. CRC16 校验

**错误处理**:
- 报文为空 → `DecodeError("报文为空")`
- 非HEX字符 → `DecodeError("报文包含非十六进制字符")`
- 奇数字节 → `DecodeError("报文长度不是偶数")`
- 非7E7E开头 → `DecodeError("报文不是以 7E7E 开头")`
- 正文长度不匹配 → `DecodeError("正文长度 … 与总长 … 不匹配")`
- 无效 BCD 数据 → 优雅降级，值显示为 `-`

**输出**: `DecodedMessage` 数据类，含报头信息、要素列表、CRC 信息、逐字节视图

### 2.7 编码器设计

**编码器**: `SL651Encoder(center_addr, station_addr, password, station_type)`

**核心方法**:

| 方法 | 状态 | 说明 |
|------|------|------|
| `build_frame(func, body, dir)` | ✅ | 通用帧构造，含 CRC 计算 |
| `build_timing_body(elements, obs_time)` | ✅ | 上行定时报正文：F1F1+站码+类型+F0F0+观测时间+要素 |
| `build_timing_frame(elements, obs_time, func=0x32)` | ✅ | 定时报帧封装 |

**待实现**:
- `build_link_maintain_frame()` — 链路维持报 (2F)
- `build_alarm_frame()` — 加报报 (33)
- `build_hourly_frame()` — 小时报 (34)，含 F5 12×2B 水位数组

**输入格式**: `elements = [(引导符, 值, 数据字节数, 小数位数), ...]`

**负数编码**: 按规约 6.6.3.3a —— 首字节 `0xFF` + BCD(abs(value))

**参数校验**:
- `station_addr` 必须为 10 位十六进制字符串，否则抛 `EncodeError`
- BCD 编码值超出 `10^(len*2)-1` 范围时抛 `ValueError`

## 三、SL427 协议

### 3.1 帧结构

**帧结构（规约表3）**

```
68 L 68 | C(1B) | A(5B) | AFN(1B) | D(NB) [| PW(2B)] [| Tp(7B)] | CS(1B CRC8) | 16
```

| 字段 | 长度 | 编码 | 说明 |
|------|------|------|------|
| 帧起始符1 | 1B | `68H` | |
| 长度 L | 1B | BIN | C+A+AFN+D+(PW+Tp) 总字节数, 范围1~255 |
| 帧起始符2 | 1B | `68H` | |
| 控制域 C | 1B(2B分帧时) | | bit7=DIR, bit6=DIV, bit5~4=FCB, bit3~0=命令类型码 |
| 地址域 A | 5B | 方式1或方式2 | 见 3.4 |
| 功能码 AFN | 1B(2B扩展时) | HEX | 见 3.2, 附录A |
| 数据域 D | NB | | 监测数据 |
| 附加信息 AUX | 0/2/9B | | PW(2B)+Tp(7B), 见 3.5 |
| 校验码 CS | 1B | CRC8 | 覆盖 C 到 AUX 全部 |
| 帧结束符 | 1B | `16H` | |

### 3.2 AFN 功能码（实现范围）

| AFN | 报文类型 | AUX | 解码 | 编码 | 说明 |
|-----|----------|-----|------|------|------|
| `02` | 链路检测 | 无 | ✅ | ✅ `build_heartbeat` | F0=登录/F1=退出/F2=在线保持 |
| `10` | 设置地址 | PW+Tp | — | — | 参数设置 |
| `11` | 设置时钟 | PW+Tp | — | — | 6B BCD 时间 |
| `12` | 设置工作模式 | PW+Tp | — | — | 1B 模式 |
| `15` | 设置充值量 | PW+Tp | — | — | 4B BCD |
| `B0` | 查询/实时值 | 无 | ✅ | ✅ `build_query_response` | 按命令类型码解析 |
| `C0` | 自报实时数据 | Tp | ✅ | ✅ `build_self_report_c0` | D+alarm(2B)+state(2B)+Tp(7B) |
| `61` | 图像数据 | Tp | ✅ | — | |
| `81` | 自报告警 | Tp | ✅ | — | 结构同 C0 |
| `82` | 人工置数 | Tp | ✅ | — | 结构同 C0 |
| `83` | 自报图片 | Tp | ✅ | — | |
| `84` | 自报电压 | Tp | ✅ | — | 2B BCD 电压 |
| `FFxx` | 用户自定义 | 按协议 | ✅ | — | 双字节 AFN 扩展 |

### 3.3 控制域 C（规约表4）

| 数据位 | 定义 | 说明 |
|--------|------|------|
| D7 | DIR | 0=下行(中心→终端), 1=上行(终端→中心) |
| D6 | DIV | 0=单帧, 1=分帧(此时 C 为 2B, 增加 DIVS 拆分计数) |
| D5~D4 | FCB | 帧计数位, 防丢失重复 |
| D3~D0 | 命令与类型码 | 见 3.4 |

### 3.4 命令与类型码（规约表5/表6）

**下行 (DIR=0, 表5)**

| 码 | 分类 |
|----|------|
| `00` | 发送/确认(命令) |
| `01~0F` | 查询/响应帧: 雨量/水位/流量/流速/闸位/功率/气象/电量/水温/水质/土壤含水率/蒸发量/报警状态/综合参数/水压 |

**上行 (DIR=1, 表6)**

| 码 | 分类 |
|----|------|
| `00` | 确认(认可) |
| `01~0F` | 自报帧: 同上 + `0D`→统计雨量 |

### 3.5 数据域 D 解析

**按命令与类型码解析**（`CTRL_FUNC_MAP`）

| 码 | 要素 | 字节数 | 符号 | 数组 | 说明 |
|----|------|--------|------|------|------|
| `01` | 雨量 | 3 | 无 | 否 | BCD LE, 1位小数 |
| `02` | 水位 | 4 | 有 | 是 | BCD LE, 3位小数 |
| `03` | 流量/水量 | 5 | 有 | 是 | BCD LE, 3位小数 |
| `04` | 流速 | 3 | 有 | 是 | BCD LE, 3位小数 |
| `0B` | 土壤含水率 | 3 | 无 | 否 | BCD LE |
| `0D` | 电压 | 2 | 无 | 否 | BCD LE, 2位小数 |
| `0E` | 综合参数 | 1+动态 | — | — | bit 位图 + 动态子要素 |

**负数编码**: 有符号类型末字节高 4 位 = `0xF` 表示负数，剥离后取反。

### 3.6 地址域 A（规约表7/表8）

**方式1**: A1 = 3B BCD(行政区划码) + A2 = 2B BIN(站址, 小端, 1~60000)

**方式2**: BYTE1 = `00H` + BYTE2~5 = 8 位 HEX 监测站编码(nibble-packed)

### 3.7 附加信息域 AUX

| AFN 类别 | PW(2B) | Tp(7B) |
|----------|--------|--------|
| 链路检测(02) | 无 | 无 |
| 自报 (C0/81/82/83/84/FF) | 无 | 有 |
| 参数设置/查询(10~9F) | 有 | 有 |

### 3.8 时间标签 Tp（规约 6.3.3.8）

- 前 6 字节: 秒/分/时/日/月/年，BCD 编码
- 第 7 字节: 允许发送传输延时时长，BIN 编码，单位 min

### 3.9 告警与终端状态

**告警状态** (2B, big-endian, 14 bits):

| bit | 告警 |
|-----|------|
| 0 | 工作交流电停电 |
| 1 | 蓄电池电压 |
| 2~4 | 水位/流量/水质超限 |
| 5 | 流量仪表故障 |
| 6 | 水泵开停状态 |
| 7 | 水位仪表故障 |
| 8 | 水压超限 |
| 10 | IC卡功能 |
| 11 | 定值控制 |
| 12 | 剩余水量下限 |
| 13 | 终端箱门状态 |

**终端状态** (2B, big-endian):

| bit | 状态 |
|-----|------|
| 0~1 | 终端工作模式（自报/确认/遥测/调试） |
| 2 | IC卡功能 |
| 3 | 定值控制投入 |
| 4 | 水泵工作 |
| 5 | 终端箱门 |
| 6 | 电源工作（AC/蓄电池） |

### 3.10 校验算法

- **算法**: CRC8, 多项式 `X7+X6+X5+X2+1` = `0xE5`, 初值 `0x00`
- **覆盖范围**: 控制域 C 到附加信息域 AUX 结束
- **验证**: CRC8(0xE5, init=0) 与报文中 CS 字段一致

### 3.11 解码器设计

**输入**: 十六进制字符串或 bytes

**处理流程**:
1. 验证 `68 L 68` 起始、`16` 结尾
2. 校验 L 与用户区实际长度一致
3. CRC8 校验用户区
4. 解析控制域 C（DIR/DIV/FCB/命令类型码）
5. 解析地址域 A（方式1/方式2）
6. 解析 AFN
7. 按 AFN 分派数据解析：
   - `02`: 心跳类型
   - `C0`: 要素数据(D) + 告警(2B) + 终端状态(2B) + Tp(7B)
   - `B0`: 查询响应数据
   - `61/83`: 图像数据
   - `81/82/84/FF`: 自报数据
   - 下行: 通用信息展示
8. 按命令类型码解析要素（有符号/无符号/数组）

**输出**: `DecodedMessage` 数据类，含帧信息、要素列表、CRC 信息

### 3.12 编码器设计

**编码器**: `SL427Encoder(addr_bytes)`

**核心方法**:

| 方法 | 状态 | 说明 |
|------|------|------|
| `build_frame(afn, ctrl, data, tp, pw)` | ✅ | 通用帧构造，含 CRC8 |
| `build_heartbeat(hb_type)` | ✅ | 链路检测帧 (AFN=02) |
| `build_self_report_c0(func, data, tp, alarm, state)` | ✅ | 自报实时数据帧 (AFN=C0) |
| `build_query_response(func, data)` | ✅ | 查询响应帧 (AFN=B0) |

**辅助函数**:

| 函数 | 说明 |
|------|------|
| `make_ctrl(dir_, func, div, fcb)` | 构造控制域字节 C |
| `encode_address(method, admin_code, stn_id, hex_code)` | 编码 5B 地址域 |
| `encode_tp(dt, delay)` | 编码 7B 时间标签 |

**待实现**:
- `build_self_report_81/82/84()` — 告警/置数/电压自报（结构同 C0，仅 AFN 不同）

|------|-----|------|----------|
| 水位站 | `WaterLevelStation` | `0x39 瞬时河道水位(4B,3位)` + `0x38 电池电压(2B,2位)` | 布朗运动+正弦周期 |
| 雨量站 | `RainStation` | `0x1F 日降水(3B,1位)` + `0x1A 1h雨量(3B,1位)` + `0x20 当前降水(3B,1位)` + `0x26 累计雨量(3B,1位)` + `0x38 电压` | 随机降雨事件状态机 |
| 墒情站 | `SoilStation` | `0x10~0x13 10~40cm含水量(2B,1位)` + `0x38 电压` | 缓慢回归+降雨影响衰减 |

### 4.2 发送器

**抽象基类**: `Sender` (`send(hex_msg, station_addr) -> bool`)

| 实现 | 说明 |
|------|------|
| `MqttxSender` | 通过 `mqttx pub` CLI 子进程发送 MQTT 消息，每次 publish 独立子进程 |
| `TcpSender` | 通过 TCP socket 直连发送原始 SL651 帧，支持断线重连 |

### 4.3 引擎

**`SimulatorEngine`**: 管理多个 `StationRunner`（每站点独立线程 + 独立编码器）

**关键参数**: 中心站址、密码、测站类型、上报间隔(秒)、功能码

### 4.4 CLI

```bash
# MQTT 模式
python tools/simulate_cli.py --type water_level --addr 1234567890 \
    --proto mqtt --broker 192.168.1.100:1883 --interval 300

# TCP 模式
python tools/simulate_cli.py --type water_level --addr 1234567890 \
    --proto sl651 --target 192.168.1.100:5001 --interval 300

# 多站点 YAML
python tools/simulate_cli.py --config examples/stations.yaml
```
