### 3.3 SL427 帧结构（表3）

- ✅ 帧格：`68 L 68 | C | A(5B) | AFN | D [| PW(2B)] [| Tp(7B)] | CS(CRC8) | 16`
- ✅ 编码器支持：链路检测 (AFN=02H)、自报实时数据 (AFN=C0H)、查询响应 (AFN=B0H)

- ✅ 地址域双格式（方式1: 行政区划BCD+站址BIN小端；方式2: 00H+8位HEX编码）
- ✅ CRC8 多项式 0xE5（X7+X6+X5+X2+1）验证通过
- ✅ 解码器增加 L 长度一致性校验

### 3.4 模拟器

- ✅ 站点要素标识符与国标对齐：水位 `0x39`、雨量 `0x1F/0x1A/0x20/0x26`、墒情 `0x10~0x13`、电压 `0x38`

- ✅ 发送器支持 MQTT (mqttx CLI subprocess) + TCP socket 双模式

### 4.2 水位站要素精度变化可能影响下游（设计决定）

`water_level_station.py:22`：水位要素从 `(0x39, ..., 3, 2)` 改为 `(0x39, ..., 4, 3)`，数据字节数从 3→4，小数位 2→3。若下游接收端按旧格式解析会出错。建议在 README 或 changelog 中标注此变化。（模拟器为开发测试工具，接收端应按定义符动态解析，不受固定格式影响）
